# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please send an email to [security@yourdomain.com](mailto:security@yourdomain.com). All security reports will be reviewed and addressed in a timely manner.

## Security Best Practices
- Keep your software and dependencies updated.
- Use strong passwords and enable two-factor authentication for accounts that have access to this repository.
- Regularly review your access logs and permissions.

## Security Updates
We will notify the community of any critical security vulnerabilities found in the project and the necessary actions taken to remediate them. You can also subscribe to our [security announcements](https://github.com/chcamp/prueba01/security/advisories).
